# Make the Judge Smile

A make.fun entry: `main.py` writes one line (185 characters, within the
200-character limit) about a small good thing that happened today to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The final line:

> Today my dad, who never texts, sent his first one: no words, just a photo of the first strawberry from his balcony pot, the size of a pea — and you can tell he thinks it's a watermelon.

See `CANDIDATES.md` for the draft lines this was chosen and refined from.
Run it with: `python3 main.py`
